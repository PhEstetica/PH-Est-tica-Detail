PRIMEIRO ACESSO APÓS ATUALIZAR
O sistema cria automaticamente o usuário mestre usando as credenciais que você já usava:
- PH_ADMIN_USER / PH_ADMIN_PASSWORD do Render, se configuradas;
- caso não existam, o padrão anterior admin / admin123.

Depois entre em Admin -> Meu acesso para trocar usuário e senha.

ATUALIZAÇÃO NO GITHUB
1. Faça backup do banco pelo painel antes de atualizar.
2. Extraia o ZIP de atualização.
3. No GitHub, envie app.py e as pastas templates e static mantendo os caminhos.
4. Confirme as alterações.
5. No Render: Manual Deploy -> Deploy latest commit.
6. Quando ficar Live, use CTRL+F5 no computador ou feche/reabra a página no celular.

BANCO DE DADOS
O pacote de atualização NÃO contém ph_estetica.db.
A migração cria somente as novas tabelas de usuários/controle de acesso dentro do banco já existente.
