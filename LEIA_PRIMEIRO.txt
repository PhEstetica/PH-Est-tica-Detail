COMO ATUALIZAR NO GITHUB:
1. Extraia o ZIP da atualização.
2. Em GitHub > Add file > Upload files.
3. Arraste app.py apenas se existir no pacote (nesta V14 não é necessário) e mantenha as pastas templates e static.
4. Confirme que o GitHub mostra caminhos como templates/home.html e static/style.css.
5. Clique em Confirmar alterações.
6. No Render, use Manual Deploy > Deploy latest commit, caso o deploy automático não inicie.
7. Quando ficar Live, atualize com Ctrl+F5 no PC. No celular, feche a aba e abra novamente.
