PH ESTÉTICA & DETAIL — V15.1
FINANCEIRO: EDIÇÃO E DETALHES DE DESPESAS

O que mudou:
- tabela de despesas separa Descrição e Fornecedor;
- colunas: Data, Descrição, Fornecedor, Categoria, Competência, Valor, Status e Ações;
- botão Editar em cada lançamento;
- botão Ver para abrir todos os detalhes da despesa;

- relatórios financeiros passam a refletir automaticamente o valor/dados editados;
- função Marcar pago e Cancelar continuam disponíveis;
- layout responsivo para PC e celular.

ATUALIZAÇÃO NO GITHUB
1. Faça um backup do banco .db pelo Admin antes de atualizar.
2. Extraia o ZIP de atualização.
3. Envie app.py e as pastas templates/ e static/ mantendo as pastas.
4. Confirme as alterações no GitHub.
5. Render -> Manual Deploy -> Deploy latest commit.
6. Depois que ficar Live, use CTRL+F5 no PC ou feche e reabra a página no celular.

O pacote de atualização não contém ph_estetica.db.
